 ÉTAPE 1 — MYSQL HOSTINGER (5 min)
 Panel : https://hpanel.hostinger.com
═══════════════════════════════════════════════════════════════

1.1 Créer la base de données
────────────────────────────
→ hPanel → "Bases de données" → "MySQL Databases"
→ Cliquer "Créer une base de données"
   • Nom de la base   : sencompta
   • Utilisateur      : sencompta_user
   • Mot de passe     : [générer un mot de passe fort, le noter]
→ Cliquer "Créer"

⚠️  NOTER ces 4 infos (nécessaires pour les variables d'env) :
   DB_HOST     = srv_____.hostinger.com  (affiché dans les détails)
   DB_USER     = u1234567_sencompta_user (préfixé auto par Hostinger)
   DB_PASSWORD = [votre mot de passe]
   DB_NAME     = u1234567_sencompta     (préfixé auto par Hostinger)


1.2 Importer le schéma SQL
───────────────────────────
→ hPanel → "Bases de données" → "phpMyAdmin"
→ Cliquer sur la base "u1234567_sencompta" dans le panneau gauche
→ Onglet "Importer"
→ "Choisir un fichier" → sélectionner schema.sql (du ZIP)
→ Cliquer "Importer" en bas de page
→ ✅ Message de succès : 4 tables créées


1.3 Autoriser les connexions distantes (CRITIQUE pour Vercel)
──────────────────────────────────────────────────────────────
→ hPanel → "Bases de données" → "MySQL Distant"
→ Activer "Accès distant"
→ Dans "Ajouter une adresse IP autorisée" :
   Entrer :  0.0.0.0/0   (autorise toutes les IP — pratique pour MVP)
   [En production, remplacer par les IPs Vercel spécifiques]
→ Cliquer "Ajouter"
→ ✅ Connexion distante activée

 ÉTAPE 3 — VERCEL (5 min)

═══════════════════════════════════════════════════════════════

3.1 Créer un compte
────────────────────
→ https://vercel.com/signup
→ "Continue with GitHub" (connecter le compte GitHub du dessus)

→ Cliquer "Deploy"
→ ⏳ Attendre 2-3 minutes
→ ✅ URL attribuée : https://sencompta-ia.vercel.app


3.4 Vérifier le déploiement

→ Ouvrir https://sencompta-ia.vercel.app/api/webhook

═══════════════════════════════════════════════════════════════
 ADAPTATION WEBHOOK — Format UltraMsg vs Meta
═══════════════════════════════════════════════════════════════

Le fichier app/api/webhook/route.js attend : { phone, message }

UltraMsg envoie :
{
  "event_type": "message",
  "instanceId": "xxx",
  "data": {
    "from": "221771234567@c.us",
    "body": "vendu riz 15000",
    "type": "chat"
  }
}

→ Modifier le début de la route webhook pour normaliser :

  // Détecter la source et normaliser
  const isUltraMsg = body.data?.from !== undefined;
  const phone   = isUltraMsg
    ? '+' + body.data.from.replace('@c.us', '')
    : body.phone;
  const message = isUltraMsg ? body.data.body : body.message;
  const audio_url = isUltraMsg && body.data.type === 'audio'
    ? body.data.mediaUrl
    : body.audio_url;

Ce patch est déjà inclus dans v2 du webhook (section suivante).
